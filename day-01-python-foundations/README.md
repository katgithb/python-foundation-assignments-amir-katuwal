## Exercises

1. Sales Summary
2. Data Quality Checker
3. File Validator
4. Customer Record Cleaner
5. Pipeline Health Status
6. Dataset Access Decision

## How to Run

Each Python exercise can be run from this directory using the following syntax:

```bash
python file-name.py
```

For example:

```bash
python exercise-01-sales-summary.py
```

Replace the filename with the exercise you want to run.

## What I Learned

In Day 1, I learned how to use Python fundamentals such as variables, data types, string methods, arithmetic operations, conditional statements, Boolean logic, lists, membership operators, and f-strings to solve practical data-related problems. I also practiced applying these concepts to calculate and validate data, clean customer records, check file formats, evaluate pipeline health, and make simple dataset access decisions.

## Challenges Faced

One of the main challenges was understanding how multiple conditions should work together when making decisions, especially in the Pipeline Health Status and Dataset Access Decision exercises. I handled this by breaking the requirements into individual conditions, checking the boundary cases carefully, and testing different scenarios to verify that the program produced the expected result.
