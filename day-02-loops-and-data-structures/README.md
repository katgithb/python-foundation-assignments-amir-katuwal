- `break` and `continue`

- List and Dictionary comprehensions

- Basic aggregation and analysis

4. Sales List Analysis
5. Dataset Comparison

## How to Run

Each Python exercise can be run from this directory using the following syntax:

```bash
python file-name.py
```

For example:

```bash
python exercise-01-batch-processor.py
```

Other exercises can be run by replacing `file-name.py` with the corresponding Python filename.

## What I Learned

In Day 2, I learned how to use Python loops and data structures to process and analyze collections of data. I practiced using `for` and `while` loops, `break`, `continue`, and the modulo operator, along with lists, list comprehensions, dictionaries, nested dictionaries, dictionary comprehensions, and sets.

I also learned how these concepts can be applied to practical data-related tasks such as batch processing, retry handling, cleaning values, analyzing sales data, comparing datasets, evaluating student scores, summarizing orders, and managing contact records through an interactive menu.

## Challenges Faced

One of the main challenges was understanding how different Python data structures and control-flow techniques should be combined to solve practical problems. The Dataset Comparison and Nested Order Summary exercises required careful use of sets and nested dictionaries, while the Retry Simulation and Contact Book exercises required managing loop conditions and deciding when to continue or stop execution.

I handled these challenges by breaking each requirement into smaller pieces, using the appropriate Python structure for each task, and testing different scenarios, including missing contacts, invalid menu choices, failed retry attempts, and empty contact lists.
